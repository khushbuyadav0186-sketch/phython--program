# Python Programs Using Google Colab

## Introduction
This repository contains three Python programs developed with AI assistance.

## Programs

### 1. Factorial of a Number
This program calculates the factorial of a number entered by the user.

### 2. Fibonacci Series
This program generates the Fibonacci series for the given number of terms.

### 3. C Structure to Python Dictionary
This program represents student details using a Python dictionary, similar to a C structure.
